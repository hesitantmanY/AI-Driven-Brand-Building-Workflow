# Brand-building 交互规格（2026-10-06）

状态：决策已完成，供实现和验收使用。本文描述目标行为，不证明产品已经实现或测试通过。来源为 [路线图](2026-10-06-interaction-improvements.md)、其 01–08 决策票、[交互审计](../2026-10-06-interaction-audit/README.md)，以及当前 CONTEXT.md / AGENTS.md。

## 1. 范围和固定约定

- 覆盖 W1–W5 的删除/清空/覆盖控件、全局档案操作、按钮状态及桌面支持边界。
- W5 证据块只读，修改去上游；不能通过图表点选改变主战场、评分或关联。
- 历史版本加载直接覆盖当前工作区，不自动创建备份。重置、Markdown 导入、W5 自动同步各自既有覆盖前存档要求独立适用。
- Work3 保持真实与模拟双来源；模拟默认参与且可勾选退出，默认包含负面反馈。已有真实文本作为种子保留，真实不足 3 条时可补足；建模采用实际纳入数量判断，不把本地真实语料数量误当全部输入。
- AI 已生成后显示「重新生成…」，点击直接覆盖上次结果；流水线重新生成清断点整组重跑，不弹额外覆盖确认。
- MVO 是步间/跨坊 CTA 的唯一显隐闸门；导航始终可用。案例模式继续遵守既有编辑、档案写入及导出保护。
- 本轮不改产品代码、schema 或 design.md；实现阶段需将 design.md 与本规格一致。

## 2. 通用对象说明、确认和反馈

删除入口的可访问名称必须包含动作、类型、对象名，如「删除候选市场：华东」。未命名对象用「未命名{类型}，第 N 项」；重名对象追加编号。语料用「删除真实语料：第 N 条」或模拟来源，正文可提供文本摘要。

仅显示图标的入口，鼠标 hover 和键盘 focus 展示同样目标说明；可访问名称始终存在。关闭弹窗用「关闭{面板}」，解除关系用「取消关联{对象}」，不能沿用删除名称。

确认界面说明对象、数量、范围、连带影响、恢复可能性。动作明确为「取消」和「删除{类型}」「清空{来源}」「导入并覆盖」「重置工作区」等；取消不执行目标变更。确认出现前不能先删除对象。关闭确认视为取消，键盘焦点留在界面内并在退出时回到触发控件；对象删除后焦点移到相邻条目或列表标题。

异步操作显示「加载中…」「保存中…」等阶段状态，并阻止重复提交。成功以服务端成功响应及有效元数据为准；失败保留可用现场并解释失败阶段，不能同时显示成功。用户编辑尚未持久化时继续显示未保存状态。

## 3. 历史版本加载（01）

历史记录常驻说明：`加载会直接覆盖当前工作区，不会自动创建恢复备份；如需保留当前内容，请先保存版本。` 自定义名永久保留、时间名保留最近 10 个的说明继续独立展示。

行内按钮仍为「加载」。每次点击均先确认，标题为「加载并覆盖当前工作区？」。

| 条件 | 正文 |
| --- | --- |
| 有未保存改动 | 当前有未保存改动。加载「{版本名}」将直接覆盖当前工作区，系统不会自动创建恢复备份。若要保留当前成果，请先取消并另存为版本。 |
| 无未保存改动 | 加载「{版本名}」将直接覆盖当前工作区，系统不会自动创建恢复备份。若要保留当前成果，请先取消并另存为版本。 |

按钮为「取消」「加载并覆盖」，默认焦点在取消。「已保存」仅说明当前工作区同步状态，不代表有可恢复的历史版本。

确认后才调用恢复；请求期间不允许连点恢复。成功后显示「已加载版本：{实际版本名}」，更新当前来源、列表及页面；正常失败保留当前内容、恢复加载按钮并显示原因。API 设置继续保留当前有效配置。

## 4. 保存、重命名和名称冲突（03）

保存入口保留版本名输入，留空使用时间名，命名版本永久保留。保存当前工作区与创建历史版本是两个阶段；创建版本失败不能显示「已存档」。

行内重命名提供输入框、「保存」「取消」及「Enter 保存 · Esc 取消」说明。失焦保留输入和编辑态，不提交也不丢弃；Enter 提交、Escape 取消。空白重命名不写入，解释名称不能为空。顶栏重命名入口也使用相同提交、取消、冲突及结果语义。

同名冲突使用明确的三选项界面，不用原生确定/取消映射两种继续操作。说明：`已存在版本「{名称}」。覆盖会替换它的旧内容；另存会保留原版本并生成可用后缀。`

| 动作 | 保存版本 | 重命名历史版本 |
| --- | --- | --- |
| 覆盖旧版本 | 当前工作区替换同名目标的内容 | 选中源版本改为目标名并替换目标内容，源旧名不继续作为独立版本保留 |
| 另存为新版本 | 当前工作区创建新的后缀名版本，原同名版本保留 | 复制选中源版本内容到新后缀名版本，源版本和冲突目标均保留 |
| 取消此次操作 | 结束此次版本创建，不新增或覆盖历史版本 | 保留原名称，结束此次重命名，不更改历史版本 |

可用后缀由服务端决定，如「终版(1)」「终版(2)」；界面不能将预估名称当实际结果。取消针对历史版本操作，不承诺撤回已由常规保存同步的当前工作区。

服务端完成后显示「已存档：{实际名}」「已重命名为：{实际名}」「已另存为：{实际名}」或「已覆盖版本：{实际名}」。复制结果新增列表条目，不能把源版本行改名；当前来源只有实际源被重命名时跟随返回的 id/name 更新，另存不自动加载或改变来源。

## 5. Work3 分来源清空（02）

只提供「清空本地真实语料」「清空模拟语料」，没有混合来源的全部清空入口。

本地真实指 Work3 手动添加/导入的 documents。Work1 开放题及主题属于上游真实来源，清空本地列表不删除它们，也不修改其纳入勾选。

| 清空目标 | 确认正文 | 确认动作 |
| --- | --- | --- |
| 本地真实 | 将删除当前 Work3 手动添加或导入的 {R} 条真实语料。{S} 条模拟语料会保留，当前{仍参与建模/未参与建模}；Work1 开放题/主题不会删除，仍按各自勾选状态参与建模。 | 清空本地真实语料 |
| 模拟 | 将删除 {S} 条模拟语料；{R} 条本地真实语料会保留。Work1 开放题/主题不会删除，仍按各自勾选状态参与建模。 | 清空模拟语料 |

两种确认均有取消。确认后使旧 LDA 结果失效，主题关联按既有规则清除；取消不失效结果。

清空反馈明确「已清空{来源} {N} 条」，同时显示剩余本地真实/模拟数量及模拟纳入状态。清空真实后模拟仍被勾选时，必须写「模拟语料仍参与建模」。模拟为 0 时写「当前无模拟语料」，不能笼统宣称所有建模输入已清空。

语料构成持续显示本地真实数量、模拟数量及纳入状态；上游 Work1 来源单独标明按勾选纳入，不能混淆存储数量与实际建模数量。建模结果及导出显示实际真实/模拟数量与占比，模拟证据逐条标注来源。少于可运行数量时显示既有补足提示。

## 6. 删除分层与控件盘点（04）

直接删除并撤销适用于没有连带失效的单项；涉及评分、派生结果、关系或整组内容时先确认。下表为实现入口清单，描述的是目标交互；清理实际数据与引用须由实现检查，不能只修改按钮文案。

| 区域/入口 | 目标和主要影响 | 交互 |
| --- | --- | --- |
| W1 竞品 | 一条竞品及所填字段 | 直接删除 + 撤销 |
| W1 场景 | 场景及其画像关联；如有依赖答卷/分析需说明 | 有关联影响先确认，无依赖单项可直接删除 + 撤销 |
| W1 画像 | 删除画像、取消场景关联；历史答卷保留但失去画像指向，编号重排 | 先确认，列出场景数和答卷数 |
| W1 清空采纳 | 全部已采纳画像和场景 | 先确认，显示各类数量与关联影响 |
| W1 一级指标/测评点 | 指标、下级测评点及有关评分/题目引用 | 先确认，列出子项和引用影响 |
| W1 问卷题目 | 一道题；已有答卷时存在统计/引用影响 | 有依赖先确认，无依赖单项直接删除 + 撤销 |
| W1 重建指标题 | 替换全部指标生成题，保留手动题 | 先确认，显示旧/新题数及保留范围 |
| W1 清空回答 | 回答、已完成记录、分析统计/主题及实测回填 | 先确认，列出数量与影响范围 |
| W2 候选市场 | 候选清单的一条市场，不代表删除保留市场 | 直接删除 + 撤销 |
| W2 筛选标准 | 标准及数据源；筛选依据可能失效 | 有派生影响先确认，否则直接删除 + 撤销 |
| W2 保留市场 | 市场详情、三档引用及评估展示受影响 | 先确认，说明决策关联清理 |
| W2 一级/二级指标 | 维度/指标、锚点、评分/权重引用受影响 | 先确认，一级显示子项数；最后一个维度需说明轴将为空 |
| W2 恢复默认模板 | 当前轴全部指标替换；persona 赋权及收敛需重定，另一轴保留 | 先确认，说明模板不会恢复删除的自填内容 |
| W2 招聘视角 | 一条视角；已赋权时可能影响 Delphi 结果 | 有依赖先确认，否则直接删除 + 撤销 |
| W2 里程碑/观察指标 | 单条里程碑可恢复；观察指标属于指标类 | 里程碑直接删除 + 撤销；观察指标先确认 |
| W3 场景 | 场景、画像关联及卖点引用 | 有引用影响先确认，否则直接删除 + 撤销 |
| W3 单条真实/模拟语料 | 当前来源中的一条；LDA 结果失效、主题关联清除 | 先确认，说明来源与结果失效 |
| W3 清空语料 | 对应来源列表，其他来源保留 | 按第 5 节 |
| W3 痛点/备选卖点 | 条目及痛点绑定、矩阵/选定值引用 | 有引用或评分先确认，否则直接删除 + 撤销 |
| W3 评分维度 | 维度及相关评分展示 | 先确认，说明评分影响 |
| W3 价值主张候选/Slogan | 删除选定项时清除选定指针，上游成果及下游引用受影响 | 选定项先确认；未选定且无引用单项直接删除 + 撤销 |
| W4 二级渠道 | 单行名称和销售占比，渠道结构图随之更新 | 直接删除 + 撤销，恢复行及占比 |
| W4 标签/关键伙伴 | 标签值，或伙伴名称与线上/线下归属 | 直接删除 + 撤销，伙伴撤销须恢复归属 |
| W4 产品/价格/广告/PR/促销表单列表 | 单行全部字段及对应文档/图表输出 | 无连带失效单项直接删除 + 撤销；有关联影响先确认 |
| W4 清空正文 | 仅 AI 叙事正文，表单及导出真相源不变 | 先确认：「清空 AI 起草的叙事正文？表单内容不受影响。」 |
| W5 证据块 | 上游成果只读引用 | 不提供删除、编辑、战略点选；提供去上游修改 |
| W5 章节导入/从 W1–4 汇总 | 对应章节或指定整组章节覆盖 | 已有内容先确认，列出章节范围；不误写成全工作区覆盖 |
| 全局历史版本删除 | 一个历史快照；不删除当前工作区内容 | 先确认对象名、不可恢复；删除当前来源时清来源标签 |

所有删除目标桌面至少 24×24 CSS px，触屏至少 44×44；视觉图标可较小，热区不重叠，不能侵入伙伴归属切换。焦点/目标提示无截断，重渲染后列表和影响状态即时一致。

## 7. 直接删除的撤销（08）

每次删除提供独立的 10 秒入口：「已删除{类型}：{名称} · 撤销」。倒计时从该条反馈出现起计；hover 或键盘焦点在入口内时暂停，移出后续计。连续删除至少三项也须保留全部有效入口，不能用新提示顶掉旧撤销。

撤销恢复原对象内容、id、位置及相关关联，不恢复整个旧 state、不覆盖后续无关编辑；派生展示按当前数据重算。步骤和工作坊导航不结束入口。

成功加载、导入、重置、进入/退出案例等整体工作区替换后全部旧撤销失效；取消或前置失败未替换工作区时保留入口。页面刷新/关闭后不承诺保留这类临时撤销。撤销引起的改动依照普通保存状态处理，保存失败明确保留未保存提示。

## 8. 全局覆盖和前置存档失败（07）

| 操作 | 覆盖范围 | 保护和交互 |
| --- | --- | --- |
| 重置 | 当前 W1–W5 内容恢复默认；保留有效 API 设置 | 确认范围与覆盖前存档；前置保存、创建「重置前存档…」均成功才继续 |
| Markdown 导入 | 嵌入数据替换当前工作坊内容，保留本机有效 API 设置 | 先解析有效数据，再确认；前置保存、创建「导入前存档…」成功才应用 |
| W5 进入即同步 | 同步既有允许更新的策划书字段；证据块只读引用 | 按既有条件自动同步，覆盖前保存并存档；保持用户修改字段的既有保护 |
| 历史加载 | 历史快照替换当前工作区 | 第 3 节确认，直接覆盖，不增加自动备份 |

重置确认：`重置将清空当前五个工作坊内容。当前内容会先保存为历史版本，API 设置保留。是否重置？` 动作为「取消」「重置工作区」。

导入确认：`导入「{文件名}」将覆盖当前五个工作坊内容。当前内容会先保存为历史版本，API 设置保留。是否导入？` 动作为「取消」「导入并覆盖」。无法解析或取消选择文件时不覆盖、不显示成功。

承诺前置存档的三类操作，保存 false、保存异常、存档失败或无有效成功元数据均停止覆盖。反馈：`未完成：当前内容未被覆盖。{保存当前内容/创建覆盖前版本}失败：{原因}。` 提供「重试」。

W5 同步失败显示「未同步最新上游成果」，当前策划书可阅读；重试重新读取最新上游和当前输入，存档期间新增输入不得被旧 patch 覆盖。不自动降为无备份覆盖。

前置步骤成功后应用覆盖，若覆盖后的保存失败，显示「内容已更新但未保存」并提供「重试保存」；不能再说未覆盖，也不能报告全部完成。

## 9. W5 证据块和上游入口

| 证据类型 | 修改入口 |
| --- | --- |
| 品牌资产/画像/调研 | 去 W1 对应步骤修改 |
| 目标市场矩阵、排名、三档决策 | 去 W2 评估或矩阵与三档决策修改 |
| 痛点地图、卖点矩阵、价值主张/定位/Slogan | 去 W3 对应步骤修改 |
| 产品、价格、渠道结构、传播预算及伙伴 | 去 W4 对应 4P 步骤修改 |

证据块可提供只读说明/查看交互，不调用上游写操作。主战场矩阵去除「点选设为主战场」，用「去目标市场修改」。不对用户显示共享 state 等实现术语。跳转只导航，不改变战略决策；回来后按进入同步规则读取最新成果。

## 10. 按钮状态及设计同步（06）

| 类型/状态 | 稳定信号 |
| --- | --- |
| 主操作、AI 起草、步间/跨坊 CTA | 黑底纸白字；方角、无阴影，沿用现有字体体系 |
| 次操作、添加 | 纸底、墨色字、描边；添加带「添加{对象}」 |
| 删除/清空/覆盖 | 明确危险动作与对象，危险色文字/描边在静止时即存在；不只靠红色或 hover 表达 |
| 当前选中 | 黑底纸白字及选中语义，hover 不丢失选中态 |
| hover | 描边强调，不上移、不展开装饰底线、不反转选中态 |
| focus-visible | 清晰蓝色焦点轮廓，不以 hover 替代键盘焦点 |
| 按下 | 内描边即时反馈；不位移、不缩放 |
| disabled | 禁用语义、降低强调、禁止动作和 hover/按下反馈；必要时附近显示原因 |
| AI 生成中/已暂停 | 明确状态文案与当前可做动作，不用位移动效表现进度 |

单调用生成中只可中止；多单元生成中主体可暂停，× 中止；已暂停只有中止出口，没有继续动作。中止保留完成单元，后续普通生成按既有断点规则补缺；显式重新生成按既有整组重跑规则。其他 AI 按钮在全局任务期间禁用，原因是「已有 AI 任务进行中」。

触屏无需 hover，也能从静态层级、危险文字、选中状态与按下反馈判断操作。实现阶段同步 design.md，移除与本规则冲突的 paper-hover 反色、active 缩放及当前通用位移描述。[对比原型 B](2026-10-06-interaction-improvements/06-button-directions.prototype.html) 为方向参考，实际业务状态机由本文和 CONTEXT 定义。

## 11. 支持宽度（05）

仅承诺宽度至少 1024 CSS px 的桌面编辑。内容最低宽度 1024px，SBU 三问与三列卡片保留可读桌面列宽；顶栏、工作坊/步骤导航以及判定横条可换行，不裁掉动作。

小于 1024px 显示：`当前窗口宽度小于 1024px，不在支持范围内。建议使用电脑或扩大窗口；下方保留桌面界面，可横向滚动。` 提示按可见视口排版，不随桌面内容横向移出；不替代界面、不增加编辑锁。密集表格局部横向滚动，受支持宽度不因其造成整页溢出。

窗口跨越断点时只改变提示呈现，不重新加载、清空输入、改变位置或未保存状态。[SBU 与评分表示意](2026-10-06-interaction-improvements/05-desktop-layout.prototype.html) 是目标布局参考，不是当前产品渲染证据。
